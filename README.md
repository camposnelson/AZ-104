🧩 Descripción

Este proyecto es una aplicación web interactiva diseñada para practicar preguntas tipo test del examen Microsoft Azure Administrator (AZ-104).

Incluye un banco de más de 600 preguntas, con opciones, evaluación inmediata, explicación del porqué y herramientas de estudio como filtros, modo examen y seguimiento de progreso.

🔗 Accede al simulador aquí:
👉 https://nelsoncampos3.github.io/AZ-104/

🚀 Características

✔ 600+ preguntas tipo examen
✔ Explicación detallada de cada respuesta
✔ Evaluación inmediata
✔ Marcar como “Dominada”
✔ Filtro por texto (servicios, acciones, recursos)
✔ Filtro por bloque (Bloques 1–12)
✔ Modo examen real (oculta pistas)
✔ Progreso en tiempo real
✔ Reiniciar progreso
✔ 100% frontend (sin backend)
✔ Funciona offline después de cargar
✔ Desplegado con GitHub Pages
